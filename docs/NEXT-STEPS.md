## 3. 가이드라인 반영 현황

### 반영 완료 (테스트·결과·리드 저장 범위)
- **문항 14개:** 워밍업 2 → 공통 3(업종·매출·외감/상장) → 4번 경로 분기(A 신규 도입 / B 교체 검토 / C 기존 유지 + 확장 / 감사 엔딩) → 경로별 5 → 마무리 3. 모든 문항에 "잘 모르겠습니다", 진행 바 처음부터 표시, 워밍업 뒤 전환 문구.
- **판단 변수 9개**와 **규모 등급 × 진입 경로 매트릭스**, **업종별 모듈 구성**(업종은 제품을 바꾸지 않음).
- **결과 유형 7종 + 감사 엔딩**, 유형별 한 줄 메시지·함께 제안.
- **예외 규칙 5개**를 우선순위대로: 아마란스10 타 부서·파트너 구매 → 감사 엔딩·이관 / 업무 전반 맞춤 설계 → OmniEsol / 매출·외감 불일치 → 높은 등급 / "잘 모름" 3개 이상 → T2 + 상담 CTA 우선 / 맞춤 키워드 → 맞춤 설계형. 마지막에 **PMS 함께 제안 규칙**.
- **결과 페이지 7개 구성:** 유형 + 한 줄 메시지(공유용 이미지 카드), 회사 요약 3줄, 주 추천 + 이유 3가지(첫 줄은 W2 답변·호칭은 W1 직무), 함께 보면 좋은 기능, 걱정 해소 문구(12번), 다음 단계 CTA(상세 리포트 / 무료 상담 / 데모), 다시 하기·공유. 1~4번은 입력 없이 공개.
- **리드 수집:** 상세 리포트(이메일·회사명 필수, 직책 선택), 상담·데모(담당자명·전화번호 추가), 감사 엔딩의 "새 기능·무료 교육 소식 받기". 개인정보(필수)·마케팅(선택) 동의 분리. 응답 전체·결과 유형·규모 등급·진입 경로 자동 저장. 리드 등급 A/B/C/이관은 서버가 계산.
- **관리자 화면:** 리드 유형·등급, 연락처, 결과 유형, 규모·경로, 도입 시기, "전체 / 리드만 / 응답만" 보기, CSV, 결과 이미지, 선택 삭제.

### 아직 하지 않은 것 (가이드라인에는 있으나 테스트 페이지 밖의 작업)
- **상세 리포트(PDF, 예상 구성·도입 절차 포함) 생성과 메일 발송:** 자동 생성·발송 없음. 지금은 관리자 화면에서 리드를 보고 담당자가 직접 보냅니다.
- **리드 등급별 후속 조치 자동화:** A(무료 상담 + 전화번호) 영업일 1일 내 전화, B 리포트 메일의 "담당자와 15분 통화 예약" 링크·3영업일 내 맞춤 메일, C EDM·뉴스레터. 신규 리드 **알림(메일·슬랙 등)도 없어서** A 등급을 놓치지 않으려면 관리자 화면을 자주 확인해야 합니다.
- **시트·CRM 연동:** Supabase 저장 + CSV 내려받기만 있음.
- **성과 지표:** 완료 수·유형별 분포·리포트 신청 전환율·등급별 분포는 DB/CSV로 계산 가능. **시작률**(시작만 하고 그만둔 수)은 저장하지 않아 측정 불가 — 방문 분석 도구 연결 필요.
- **결과 유형별 이미지 카드·일러스트·쇼츠:** 지금은 7종 공통 템플릿 1개(온이·원이 캐릭터 포함).
- **제작 순서 5~7:** 과거 고객사 10곳 내부 테스트, 배포 채널(네이버 블로그 '기록의 궤도', EDM, 전시회 부스 QR), 4주 운영 후 보정.

### 구현하면서 임시로 정한 것 (영업팀 검토 권장)
- **선택지 문구:** 가이드라인에 문항만 있고 선택지가 없는 문항(A·B 5~7·9번, C 5·7~9번, 마무리 10~12번)의 선택지는 초안으로 작성했습니다. `erp-rules.js`의 `options`와 `erp.js`의 `questions`에서 고칩니다.
- **4번 분기 선택지:** "엑셀·수기"와 "세무사무소 기장"을 따로 나눴습니다(둘 다 경로 A). C 경로 선택지는 "더존 ERP(아마란스10·WEHAGO)를 그대로 쓰면서 기능을 더하고 싶음"으로 WEHAGO도 포함했고, 감사 엔딩 이관은 아마란스10만 해당합니다.
- **C 경로 5번 "도입한 곳" 선택지:** 아이원소프트뱅크 / 다른 파트너사 / 본사·다른 부서 / 잘 모름. 다른 파트너사·본사 부서이면 이관.
- **A 경로 + T4(매출 1,000억 이상 신규 도입):** 결과 유형 표에 없어 체계 완성형(아마란스10 확장 구성 + SI)으로 안내.
- **ONE AI:** 가이드라인 제품 체계에 없어 추천에서 제외(이전 응답 표시용으로만 남김).
- **함께 보면 좋은 기능:** 업종별 모듈 표의 "함께 제안" 항목을 씁니다. 이미 PMS를 제안한 경우에는 핵심 모듈을 보여 줍니다.
- **DB의 `score` 칸:** v3에서는 쓰지 않아 0으로 저장(기존 스키마 호환용).
- **개인정보 보유 기간:** 신청일로부터 1년으로 안내. 자동 삭제 작업은 없어 운영자가 삭제해야 합니다.
