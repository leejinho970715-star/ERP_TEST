# ERP 가상 컨설팅 기획 검토 및 v2 반영

검토일: 2026-10-20. 결론: 짧은 진단을 통해 상담 준비와 제품 후보의 검토 방향을 제공하는 것은 현실적입니다. 다만 5문항으로 ERP 적합도·기업 성숙도·구매 확률을 정량 판정하거나 도입 성과를 예측할 근거는 아직 없습니다.

## 기존 기획에서 유지한 점

- 회사 정보 → 현재 환경 → 업무 수요 → 결과의 흐름은 자연스럽습니다.
- 업종별로 살펴볼 업무가 다르다는 관점은 유용합니다.
- 더존 기존 고객의 활용 개선과 PMS 확장, 신규 도입과 맞춤 연계를 구분하려는 방향을 유지했습니다.
- 제품 이미지, 랜덤 강아지, 폭죽 효과는 추천 규칙과 분리했습니다.

## 참고 근거와 적용 범위

[SAP ERP 평가 안내](https://www.sap.com/resources/how-to-evaluate-erp-software)는 업무·거래량·프로세스 복잡도, 현재 시스템의 장단점과 필수 요구사항을 확인하고 실제 시연으로 후보를 비교하도록 설명합니다. 이를 근거로 기존의 규모 중심 점수 대신 요구사항 중심 분기로 바꿨습니다.

[Microsoft 구현 지침](https://learn.microsoft.com/en-us/dynamics365/guidance/implementation-guide/solution-architecture-design-pillars-technology)은 맞춤화에 앞서 요구사항과 구현 대안을 검토하도록 안내합니다. 별도 개발을 선택했다고 특정 제품이 자동으로 맞는다고 단정하지 않도록 반영했습니다.

[더존 제품 안내](https://www.douzone.com/product/bportal.jsp)는 Amaranth 10의 ERP·그룹웨어·문서 통합 영역과 WEHAGO·OmniEsol의 제품 범위를 확인하는 데 사용했습니다. 이 자료가 특정 매출 기준이나 이번 추천 알고리즘의 정확도를 입증하는 것은 아닙니다.

추천 대상은 아이원소프트뱅크가 취급하는 더존 제품입니다. 따라서 **시장 전체에 대한 중립적인 제품 순위로 볼 수 없습니다.** 사이트와 결과 이미지에 범위를 명시했습니다. 같은 업무 조건을 가진 응답에 업종·매출·인원만 달라졌다고 상위 제품을 권하지 않는다는 의미에서 일관성을 개선했습니다. 모든 기업에 대해 적합성이 검증됐다는 의미는 아닙니다.

## 5개 질문 영역

1. 현재 관리 도구와 실제 불편: 중복 입력, 데이터·보고 문제, 불편 없음, 확인 필요.
2. 업종: 상담에서 확인할 업무 맥락에만 사용.
3. 현재 ERP: 더존은 제품명과 자기평가 활용도, 그 외는 관심 영역.
4. 기업 상황: 매출·인원 참고 정보와 단일 조직/복수 사업장/복수 법인·해외 운영 범위.
5. 실제로 보완할 기능과 별도 개발·연계 여부. 보완 필요 없음·확인 필요를 허용.

선택해야 하는 세부 항목이 늘어난 만큼 예상 소요 시간을 약 3분으로 표시했습니다. 이전 공유 링크의 누락된 새 항목은 임의로 추정하지 않고 확인 필요로 처리합니다. 공유 링크 결과는 최신 규칙으로 다시 검토한다고 표시합니다.

## v2 분기

1. 핵심 정보가 미확인되거나 불편이 있는데 보완할 기능이 없다고 답한 경우 → **요구사항 확인 우선**. 신규 제품을 강제하지 않음.
2. 보완 기능이 없거나 표준 업무에서 불편이 없다고 답한 경우 → **현재 방식 유지·점검**.
3. 기존 ERP와 표준 업무가 있는 경우 → **기존 ERP 활용 개선**. 보유 모듈·설정·교육을 우선 확인.
4. 별도 개발·연계 또는 여러 법인·해외 운영 수요 → **표준 기능·확장 방식 비교**. Amaranth 10·OmniEsol 후보 비교. 이미 OmniEsol을 사용하면 기존 환경 점검 우선.
5. ERP 미사용 상태에서 생산·재고·원가, 프로젝트, 분석 수요 → **업무 통합 검토**. Amaranth 10 후보.
6. 나머지 회계·인사·협업 중심 신규 수요 → **기본 경영 관리 검토**. WEHAGO 후보.
7. 더존 사용 + 프로젝트 수요에서 PMS 검토 후보 추가. 타사 ERP와의 연계 가능성이 확인되지 않아 타사 사용자에게 PMS를 자동 추천하지 않음.
8. Amaranth 10이 포함되면 ONE AI를 선택형 동반 검토로 표시. 이미 사용 중인 Amaranth 10은 신규 구매 후보와 구분해 기존 제품 활용으로 표시.

이는 판매 제품의 일반적인 기능 범위를 바탕으로 만든 설명 가능한 **예비 검토 규칙**이며, 개별 모듈의 지원·도입 성공·가격·성능을 보장하지 않습니다. 제품 교체를 확정하지 않으며, 실제 요구사항 시연과 비용 비교가 다음 단계입니다.

## 실효성을 확인할 다음 단계

아직 실사용 고객의 정확도·전환율·비용 절감 효과를 검증하지 않았습니다. 자동 테스트는 규칙의 일관성과 소프트웨어 동작을 검증할 뿐, 사업적 성과를 입증하지 않습니다.

초기에는 다양한 업종·규모·ERP 사용 상황의 상담 사례 20–30건으로 사용성과 누락 요구사항을 탐색하는 파일럿을 권합니다. 이는 통계적 효과 입증에 충분한 표본이라는 뜻이 아닙니다. 상담 담당자가 진단 결과를 보기 전에 검토 방향과 후보를 기록하고 나중에 비교하면 유도 효과를 줄일 수 있습니다.

확인할 지표는 진단 완료율·소요 시간, 상담자가 후보/유지 방향에 동의하는 비율, 불필요한 신규 구매 권유 사례, 추가 확인 항목의 누락, 실제 시연 후 후보 변경 이유입니다. 계약률만으로 추천의 질을 판단하지 말고 도입 불필요 고객을 적절히 제외하는지도 확인해야 합니다.

최종 상담에는 실제 ERP 사용 인원·거래량·품목/창고·법인/통화·필수 연계·예산·도입 일정·책임자·데이터 정리 상태를 추가 확인하도록 결과에 안내합니다. 도입 효과는 고객별 총비용과 현재 반복 업무 시간·오류 등을 확인한 뒤 따로 검토해야 합니다.

## 저장·배포 호환

- 규칙 버전: `erp-2026-10-v2`. 프런트엔드·서버의 공유 규칙으로 동일하게 계산합니다.
- DB 스키마를 파괴적으로 변경하지 않고 `answers`와 `breakdown` JSON에 새 응답·검토 방향을 저장합니다.
- 기존 `score NOT NULL` 필드는 스키마 호환을 위해 보완 기능 개수 × 20을 기록합니다. 추천 임계값·고객 레벨·성숙도로 사용하지 않습니다. v2 관리자 화면과 CSV에는 검토 방향을 표시하고 v1 점수는 버전을 구분해 표시합니다.
- 과거 저장 응답은 수정하지 않습니다. 기존 공유 링크는 최신 규칙으로 재검토하고 새 정보가 없으면 추가 확인을 안내합니다.
