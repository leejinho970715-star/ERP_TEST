# 모바일 반응형 점검

2026-10-20, 로컬 미리보기의 Chromium 뷰포트 시뮬레이션으로 확인했습니다. 실제 iPhone/Safari·Android 기기 테스트를 의미하지 않습니다.

## 수정

- 430px 뷰포트에서 대시보드 이미지가 본문보다 약 1px 넓어지는 현상을 이미지 너비 제한으로 해결. 가로 숨김으로 본문을 잘라내지 않음.
- flex/grid의 최소 너비와 긴 회사명·선택값·제품 설명·PDF 안내의 줄바꿈 보완.
- 모바일 입력 글자 16px 및 충분한 입력창 높이. iOS 입력 초점 확대를 방지하도록 CSS 조정했으나 실제 iOS 검증은 별도 필요.
- 작은 화면의 이전/다음 버튼과 진행 안내를 두 줄 그리드로 배치. 좁은 업종 선택 화면은 한 열로 전환.
- 640px 이하 제품 카드 한 열, 배지와 아이콘이 카드 안에서 함께 배치되도록 최소 너비·크기 조정.
- 개인정보 동의·내용 보기·모달 닫기·PDF 다운로드의 터치 영역 보강. 짧은 가로 화면의 모달은 내부 스크롤 허용.
- 관리자 본문을 화면 너비에 제한하고 표 안에서만 가로 스크롤. 스크롤 안내와 키보드 접근 가능한 표 영역 추가.
- 헤더·푸터의 공통 배경 유지, 하단 안전 영역 여백 반영.

## 제품소개서 검증

네 파일 모두 로컬 서버에서 HTTP 200 / `application/pdf`를 반환하고, 원본·브라우저 제공 파일·`dist` 파일의 바이트가 동일함을 확인했습니다. 결과 카드에 제품별 링크와 다운로드가 렌더링되며 ONE AI는 통합본 `#page=7`로 연결됩니다. IAB에서 새 탭 링크 클릭은 별도 PDF 뷰어 탭을 표시하지 않았으므로 해당 환경의 내장 PDF 뷰어 렌더링은 확인하지 못했습니다. 모바일 PDF 처리 및 페이지 fragment 지원은 브라우저에 따라 다르므로 다운로드 대안과 페이지 안내도 제공합니다.

`npm test`: 기존 규칙·API 테스트 22개 통과. `npm run build` 통과. 계산 규칙/DB 변경 없음.
