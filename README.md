# ERP 가상 컨설팅 진단

아이원소프트뱅크의 ERP 추천 진단 사이트입니다. 기존 AX/DX 사이트의 디자인 방향을 참고해 5문항 진단·추천 결과·응답 관리 화면을 구현했습니다.

## 실행

Node.js 22.18 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```powershell
npm run dev
```

- 진단: `http://127.0.0.1:4173/`
- ERP 응답 관리: `http://127.0.0.1:4173/erp-admin.html`
- 테스트: `npm test`
- 배포 파일 생성: `npm run build` → `dist/`

## 진단 흐름 (v3 · 「ERP 추천 테스트 기획 가이드라인」 2026-10-23)

1. 시작 화면 → 워밍업 2문항(직무·시간이 드는 업무) → 공통 3문항(업종·연 매출·외감/상장).
2. 4번 문항(현재 회계·경영 관리 방식)으로 경로를 나눕니다: A 신규 도입 · B 교체 검토 · C 기존 유지 + 확장 · 감사 엔딩.
3. 경로별 5문항 → 공통 마무리 3문항(구축 형태·도입 시기·걱정되는 점). 총 14문항이며 모든 문항에 “잘 모르겠습니다”가 있습니다.
4. 결과는 입력 없이 바로 공개합니다: 유형 이름 + 한 줄 메시지, 우리 회사 요약 3줄, 주 추천 + 추천 이유 3가지, 함께 보면 좋은 기능, 걱정 해소 문구, 다음 단계 CTA, 다시 하기·공유.
5. 상세 리포트(이메일·회사명 필수, 직책 선택), 무료 상담·데모(담당자명·전화번호 추가), 소식 받기(감사 엔딩)를 고를 때만 연락처를 받습니다. 개인정보 수집·이용(필수)과 마케팅 수신(선택)은 따로 동의받습니다.

추천은 점수 합산이 아닌 규칙(규모 등급 T1~T4 × 진입 경로)으로 정하고, 업종은 모듈 구성만 바꿉니다. 예외 규칙(아마란스10 타 부서·파트너 구매 → 감사 엔딩·이관, 업무 전반 맞춤 설계 → OmniEsol, 외감·회계팀 상향, “잘 모름” 3개 이상 → T2 + 상담 우선, 맞춤 키워드 → 맞춤 설계형)과 PMS 함께 제안 규칙은 `supabase/functions/_shared/erp-rules.js`에 있으며, 브라우저와 서버가 같은 파일을 씁니다.

이 사이트는 더존 제품 범위 내의 예비 제안이며 기업 레벨·공식 인증·구매 확률을 판정하지 않습니다. 현실성·근거·변경 기준·실효성 검증 계획은 [기획 검토 보고서](docs/PLANNING-REVIEW.md)에 정리했습니다.

## 데이터 연결

기존 Supabase 프로젝트 `uzvonfdifmbqdrsxzbcm`에 추가한 `erp_consulting_responses` 테이블과 `erp-consulting` Edge Function을 사용합니다. 기존 AX/DX 테이블·함수와 분리되어 있습니다. 브라우저 설정은 `erp-config.js`이며 서버 키와 관리자 토큰은 Supabase에서만 관리합니다.

관리자 화면은 기존 프로젝트의 `ADMIN_TOKEN`으로 서버 인증하며 키를 브라우저 저장소에 보관하지 않습니다. 관리자 조회·페이지 추가 로딩·CSV 다운로드를 제공합니다.

## 배포

ERP_TEST를 새 Vercel 프로젝트로 가져오면 `vercel.json`의 빌드·출력 설정을 사용합니다. 이번 작업에서는 Supabase 함수를 배포했으며 새 Vercel 프로젝트는 생성하지 않았습니다. 기존 `axdx-test.vercel.app` 배포는 변경하지 않았습니다.
